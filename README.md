# Agencia Radar Digital · versión 2.0

Aplicación estática para la Actividad 1 de Analítica Web (Universidad de La Salle).

## Funciones
- Configuración de marca, competidores y mercado (por defecto Nike, Adidas, Puma y Under Armour).
- Enlaces de investigación hacia canales y bibliotecas de anuncios.
- Registro de hallazgos con fuente, fecha y métrica visible opcional.
- Dashboard de cobertura de investigación y matriz comparativa.
- Informe ejecutivo imprimible y exportación a JSON / CSV.
- Guardado local en el navegador e importación de JSON para colaboración entre integrantes.

## Limitaciones honestas
No hace búsqueda ni extracción automática: sin API ni servicio backend, eso no sería verificable. No fabrica cifras ni resultados de compañías. Los miembros deben aportar enlaces y observaciones reales.

## Publicación
Subir `index.html` y `README.md` a un repositorio público y activar GitHub Pages desde la rama principal, carpeta raíz.

## Colaboración
Los datos se guardan en el navegador de cada integrante. Para combinar trabajo, acuerden una persona que recopile los archivos JSON; al importar un JSON se sustituye el estado anterior de ese navegador, por lo que conviene exportar una copia antes de importar.
